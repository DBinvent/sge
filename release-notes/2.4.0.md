# Schema Guard Enterprise 2.4.0

2026-11-19. Needs schema_guard_tokio 2.4.

## New

- **A database each, by feature.** The `sge` binary is PostgreSQL's (`postgres`, on by default);
  `sqlite` (embedded, through turso) and `mysql` (through sqlx) bring the deploy and the catalog
  read for those databases.
- **sge-sqlite and sge-mysql**: sge's core for SQLite and for MySQL, a binary each. A directory
  applied in sge's order, each file once, kept in the same `sge_history` table.
- **A schema moves between PostgreSQL, MySQL and SQLite**: a snapshot says its `source`
  (`postgres.<version>`), and another vendor's schema is mapped on the way in.

## Changed

- A crate that uses sge as a library without the default features names `postgres` to keep it.

## Fixed

- `bpchar(n)` in a snapshot keeps its length.
